# 📚 4주차 요약

<br/>

## 🧩 전체 주제

- 네트워크 계층별 주소 체계 및 전송 방식
- OSI 7계층 및 TCP/IP 모델 이해
- TCP, UDP, IP 패킷 구조 및 연결 동작 분석

<br/>

## 📌 주요 개념 5가지

| 개념 | 요약 설명 |
|------|-----------|
| 네트워크 주소 체계 | MAC, IP, Port, FQDN 등 계층별 주소 구조와 매핑(DNS, ARP, RARP) 방식 |
| 전송 방식 유형 | 유니캐스트, 브로드캐스트, 멀티캐스트의 대상 범위 및 MAC/IP 처리 방식 |
| OSI 7계층 & TCP/IP | 각 계층의 역할과 주요 프로토콜, 실제 구현에 따른 통합 계층 비교 |
| TCP 3/4-way Handshake | 연결지향 통신을 위한 TCP의 연결 설정 및 종료 절차 |
| IP 단편화 & MTU | MTU 제한을 초과하는 경우 IP 패킷이 조각화되어 전송되는 메커니즘 |

<br/>

## 🧪 실습 요약

### 실습 주제 1 : Cisco Packet Tracer로 장비 동작 실습
- ipconfig, arp -a, ping 명령으로 주소 정보 및 ARP 동작 확인
- Switch의 MAC 주소 테이블 (show mac-address), Router의 Routing Table (show ip route) 확인
- DNS 서버 구성 및 hosts 파일 수동 설정으로 도메인 매핑 실습

### 실습 주제 2 : Wireshark 활용
- Promiscuous Mode 설정 및 패킷 캡처
- TCP/UDP/IP 헤더 구조 확인
- Capture/Display 필터로 패킷 탐색 및 분석

## 🧠 느낀 점 / 개선 아이디어

- 계층별로 주소가 분리된 구조는 처음엔 복잡해 보였지만, 보안성과 확장성을 위한 필연적 설계임을 이해하게 되었음 → 실제 장비에서 주소 변화 흐름을 시각화하면 더 직관적일 듯
- Wireshark에서 수많은 패킷을 분석하다 보니 목적성 있는 필터링 스킬의 중요성을 느낌 → 특히 Display 필터 예제 학습을 병행할 것
