# 📚 1주차 요약

<br/>

## 🧩 전체 주제

- 웹 크롤링 및 데이터 수집 자동화
- 다양한 파일 포맷(CSV, Excel, JSON)으로 데이터 저장
- SQLite를 활용한 로컬 데이터베이스 관리
- 데이터 전처리 및 정제
- 데이터 변환 및 스케일링
- 지도학습 기반 회귀 및 분류 모델 학습
- 머신러닝 모델의 성능 평가와 개선 전략 이해

<br/>

## 📌 주요 개념 5가지

| 개념 | 요약 설명 |
|------|-----------|
| 웹 스크래핑 | BeautifulSoup을 활용해 HTML 문서에서 원하는 데이터를 추출하는 기술 |
| 데이터 정제 | 결측치 처리, 중복 제거, 이상치 탐지 등으로 데이터 품질 향상 |
| 선형 회귀 | 입력과 출력 사이의 선형 관계를 기반으로 값을 예측하는 회귀 알고리즘 |
| 로지스틱 회귀 | 분류 문제에 사용되는 확률 기반 모델로, 시그모이드 함수를 통해 예측 |
| KNN 알고리즘 | 가장 가까운 K개의 이웃 데이터를 기준으로 예측하는 분류/회귀 알고리즘 |

<br/>

## 🧪 실습 요약

### 실습 주제 1 : 파이썬을 통해 웹 크롤링해보기
- requests로 웹 페이지 요청
- BeautifulSoup으로 HTML 파싱 및 데이터 추출
- Selenium으로 동적 웹 페이지 조작 및 데이터 수집

### 실습 주제 2 : 파이썬을 통해 수집한 데이터를 다양한 형식으로 저장해보기
- CSV, Excel, JSON으로 저장 및 불러오기
- pandas 및 json 모듈 활용

### 실습 주제 3 : 파이썬을 통해 SQLite 데이터베이스 관리해보기
- 데이터베이스 생성 및 연결
- 테이블 생성 및 CRUD 쿼리 실행

### 실습 주제 4 : 웹 서버 로그 분석
- 정규표현식으로 주요 항목 추출 후 CSV 저장 및 시각화
- `/admin` 경로 요청 탐지 및 상태코드 필터링

### 실습 주제 5 : 서울시 스타벅스 매장 데이터 분석
- 결측치 제거, 구별 매장 수 집계 및 시각화

### 실습 주제 6 : 지하철 2호선 강남역 혼잡도 분석
- 공공데이터 활용, 시간대별 평균 혼잡도 시각화

### 실습 주제 7 : 지도학습 - 선형 회귀 모델 실습
- 학생 성적 데이터셋을 활용한 수치 예측
- 전처리, 학습, 평가 (MSE, R² 등)

### 실습 주제 8 : 지도학습 - 분류 모델 실습
- 유방암/아이리스 데이터셋을 활용한 로지스틱 회귀, KNN 실습
- 성능 평가 지표(정확도, 정밀도, 재현율, F1-score) 확인

## 🧠 느낀 점 / 개선 아이디어

- requests/BeautifulSoup은 간단한 정적 크롤링에 적합하고, Selenium은 실제 브라우저와 유사해서 활용도가 높음 → 용도에 따라 적절히 선택해야 겠다고 느꼈다
- 다양한 저장 방식 실습이 실제 데이터 파이프라인에 어떻게 연결되는지 감을 잡는 데 유익했다
- 데이터 정제와 변환의 중요성을 체감 → 실습에서 직접 다뤄보니 모델 학습 전에 데이터를 처리하는 것이 생각한 것보다 더 중요하다는 것을 알게 되었다
- 선형 회귀 모델 학습에 사용되는 함수들을 익힐 수 있었다
- 분류 모델은 평가 지표 선택이 중요하다는 점을 느꼈고, 특히 클래스 불균형 시 정확도 외의 지표도 꼭 고려해야겠다고 느꼈다
