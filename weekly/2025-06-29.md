## 📌 주요 개념 

### 1. 데이터 수집 및 저장 기초

#### 데이터 수집 방법

| 방법 | 설명 |
|------|-----|
| 웹 스크래핑 | HTML 파싱 (`BeautifulSoup`) |
| API 활용 | JSON 기반 응답 (`requests`) |
| 동적 웹 페이지 | 자바스크립트 렌더링 → `Selenium` |
| 공개 데이터셋 | Kaggle, 공공데이터포털 등 |
| 데이터베이스 | SQL 기반 쿼리 |
| IoT/소셜미디어 | 실시간/API 기반 수집 |

#### 데이터 저장 형식
| 형식 | 특징 |
|------|-----|
| CSV | 경량, 구조화 |
| Excel | 서식 포함 |
| JSON | 계층 구조 표현 |

#### SQLite 사용
- `sqlite3.connect()`, `cursor.execute()` 기반으로 경량 RDBMS 활용

### 2. 데이터 전처리와 변환

#### 전처리 프로세스
1. 수집
2. 정제 (결측치, 오류, 중복, 이상치 처리)
3. 변환 (스케일링, 인코딩)
4. 통합 (병합, 일관성 유지)

#### 결측치 처리 방법
| 방법 | 상황 |
|------|-----|
| 제거 | 결측치 비율이 적을 때 |
| 평균/중앙값 대체 | 수치형 |
| 예측 기반 | ML 모델 활용 |

#### 이상치 탐지
- IQR, Z-score 기반 처리

#### 스케일링 비교

| 구분 | 표준화 | 정규화 |
|------|--------|--------|
| 수식 | (x - μ)/σ | (x - min)/(max - min) |
| 사용 모델 | KNN, SVM | NN, 회귀 |
| 이상치 영향 | 적음 | 큼 |

#### 범주형 인코딩
| 인코딩 방식 | 사용 시기 |
|-------------|-----------|
| Label Encoding | 순서 있음 |
| One-Hot Encoding | 순서 없음 |

### 3. 통계 분석과 시각화

#### 중심 경향
- 평균 (민감), 중앙값 (강건), 최빈값 (범주형)

#### 분산 척도
| 척도 | 설명 |
|------|-----|
| 분산 | 제곱거리 평균 |
| 표준편차 | 분산의 제곱근 |
| IQR | Q3 - Q1, 이상치 탐지에 사용

#### 시각화
| 그래프 | 용도 |
|--------|-----|
| 히스토그램 | 분포 확인 |
| 박스플롯 | 이상치 및 사분위수 |
| 산점도 | 변수 간 관계 |
| 히트맵 | 상관계수 |
| 페어플롯 | 변수 간 전체 관계 |

#### 그룹화 & 집계
- `groupby()`, `pivot_table()`로 다차원 통계

#### 상관관계 vs 회귀
- 상관계수: 관계 세기
- 회귀분석: 선형 함수 추정, R²로 성능 평가

### 4. 지도학습 - 회귀

#### 회귀 모델
- 단순/다중 선형 회귀
- $y = mx + b$ 구조

#### 손실 함수
| 지표 | 설명 |
|------|-----|
| MSE | 제곱 오차 평균 |
| RMSE | MSE의 제곱근 |
| MAE | 절대 오차 |
| R² | 결정 계수 (0~1) |

#### 과적합/과소적합
| 유형 | 특징 | 해결책 |
|------|------|--------|
| 과소적합 | 단순함 | 모델 복잡도 증가 |
| 과적합 | 복잡함 | 정규화(L1/L2), 교차검증 |

### 5. 지도학습 - 분류

#### 로지스틱 회귀
- 선형 모델 + 시그모이드 함수 → 확률 반환
- 손실 함수: Log Loss

#### 분류 성능 지표
| 지표 | 의미 |
|------|-----|
| Accuracy | 전체 중 맞춘 비율 |
| Precision | 예측 Positive 중 실제 Positive |
| Recall | 실제 Positive 중 예측 성공 비율 |
| F1-score | Precision-Recall 균형 |

#### KNN
- Lazy learning, 거리 기반 분류
- 하이퍼파라미터 `K` 선택 중요 (교차 검증 사용)

### 6. 비지도학습 - 군집화, 차원 축소, 이상치 탐지

#### KMeans
- 유클리드 거리 기반 클러스터링
- 최적 K 탐색: Elbow, Silhouette Score 활용

#### 계층적 군집화
- 덴드로그램 기반 병합/분할 방식

#### DBSCAN
- 밀도 기반, 이상치 감지 가능
- ε, MinPts 설정 중요

#### PCA
- 고차원 → 저차원 축소
- 주성분은 분산이 큰 방향
- 시각화/과적합 방지에 효과적

#### 이상치 탐지
| 방법 | 특징 |
|------|-----|
| Isolation Forest | 분리 깊이 기반, 고속 |
| DBSCAN | 밀도 기반 이상치 감지 |

### 7. 딥러닝 기초 - ANN

#### ANN 구조
- 입력층 → 은닉층 → 출력층
- 뉴런 = (입력 * 가중치 + 편향) → 활성화 함수

#### 활성화 함수
| 함수 | 특성 |
|------|------|
| ReLU | 비선형, 빠름 |
| Sigmoid | 이진 분류 |
| Softmax | 다중 클래스 분류 |

#### 손실 함수
| 문제 유형 | 손실 함수 |
|-----------|------------|
| 회귀 | MSE |
| 분류 | Cross-Entropy |

#### 역전파
- Chain rule 기반 미분 → 경사 하강법으로 가중치 업데이트

### 8. CNN & RNN

#### CNN 구조
1. Convolution Layer
2. Activation (ReLU)
3. Pooling
4. Fully Connected
5. Softmax

#### RNN 구조
- 이전 출력값을 현재 입력에 반영 (순차 구조)
- 개선형: LSTM, GRU

### 9. OpenAI API 구조

#### 메시지 역할 구조
| role | 용도 |
|------|------|
| system | 규칙 및 톤 설정 |
| user | 입력 |
| assistant | 응답 |

#### Function Calling
- 모델이 JSON 형태로 함수 호출 응답 생성
- 앱이 함수 실행 후 결과 재전송 → 최종 응답 생성

#### Tools
- `file_search`, `web_search`, `code_interpreter` 등 도구와 연동 가능
- `tool_choice`로 자동/명시적 사용 설정

### 10. FastAPI vs Flask

#### FastAPI
- 비동기 지원(ASGI), 높은 성능
- Swagger/ReDoc 문서 자동 생성
- `Pydantic`으로 타입 기반 데이터 검증
- `uvicorn`으로 실행

#### Flask
- WSGI 기반, 마이크로 프레임워크
- Jinja2 템플릿, 정적 파일 지원
- 세션, 쿠키, 파일 업로드 등 웹 기능 지원
