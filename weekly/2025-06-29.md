## 📌 주요 개념 5가지

| 개념 | 요약 설명 |
|------|-----------|
| 비지도학습 & K-Means | 라벨 없이 데이터를 유사도 기반으로 군집화. 대표 알고리즘은 K-Means |
| 인공신경망(ANN) | 입력-은닉-출력층 구조. 뉴런 단위로 입력을 가중합 후 활성화함수로 출력 |
| CNN & RNN | CNN은 이미지 특징 추출에, RNN은 시계열 데이터에 특화된 딥러닝 구조 |
| Function Calling | GPT 모델이 외부 함수(JSON 기반)를 호출해 실질적 기능을 수행하도록 구성 |
| FastAPI & Flask | Python 웹 프레임워크. FastAPI는 타입 기반 자동 문서화, 비동기 처리에 강함 |

## 🧪 실습 요약

### 실습 주제 1 : 머신러닝 실습  
- Red Wine Dataset → KMeans 클러스터링  
- Credit Card Fraud Dataset → Isolation Forest / DBSCAN을 이용한 이상치 탐지  

### 실습 주제 2 : 딥러닝 실습  
- make_classification → 이진 분류 모델 (TensorFlow/Keras)  
- MNIST 손글씨 분류 → 다중 분류 모델 구축  
- 모델 저장 및 재사용 (.keras, joblib/pickle)

### 실습 주제 3 : OpenAI API 활용  
- GPT-4.1 + Function Calling → 날짜 계산, 날씨 조회, 환율 변환 등 함수 연동  
- 콘솔 챗봇, 텍스트 대화 응답 흐름 구성  

### 실습 주제 4 : Streamlit 기반 챗봇 및 UI 개발  
- 실시간 응답 스트리밍, 대화 기록 저장, 영어 튜터 챗봇 구현  
- 사용자가 역할 설정, 번역/피드백 기능 포함  
- 파일 검색 도구 연동 → 업로드 문서 기반 응답 생성

### 실습 주제 5 : 이미지 분류기 및 API 서버  
- cat_dog_classifier 모델을 Streamlit UI에 탑재하여 이미지 분류기 앱 제작  
- FastAPI 구조 및 Pydantic, Swagger UI 이해  
- Flask의 경량 구조 및 HTML 템플릿 처리 방식 비교

## 🧠 느낀 점 / 개선 아이디어

- 다양한 딥러닝/웹 기술들을 연계하며 **단일 챗봇 앱에 여러 기능을 통합**할 수 있음 → 챗봇 외 응용 서비스로 확장 가능  
- Streamlit의 빠른 UI 개발이 인상 깊었지만, 복잡한 인터페이스는 FastAPI + JS 기반 구조로 분리하는 것이 더 적합할 수 있음  
- 챗봇, 이미지 분류기, API 문서 등 모두 연결되는 구조 속에서 **실제 서비스로 발전시키는 구상**이 가능했음
