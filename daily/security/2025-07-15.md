## 🧠 주요 개념 정리

### 1. Multilayer Switch (L2, L3, L4, L7)

#### L2 Switch (데이터 링크 계층)
- **MAC 주소 기반의 프레임 포워딩**
- VLAN 구분 기능 가능
- 브로드캐스트 제어 불가 (→ L3 필요)
- 기본적인 사내망 접근 계층에서 사용

#### L3 Switch (네트워크 계층)
- **IP 주소 기반 라우팅 기능 포함**
- **인터 VLAN 라우팅, Access Control List(ACL), Static/Dynamic Routing**
- 사내망에서 가장 많이 사용되는 멀티레이어 스위치
- **게이트웨이 역할** 가능

#### L4 Switch (전송 계층)
- **TCP/UDP 포트 번호 기반 부하 분산**
- **Load Balancing** : 서버 다수에 트래픽 분산
- **Health Check** : ping, ARP, HTTP 등으로 서버 상태 확인
- **Active-Active/Standby** 방식의 이중화 지원
- **HTTP, FTP, SMTP 등 포트 기반 분기**

#### L7 Switch (애플리케이션 계층)
- **HTTP URL, 쿠키, 헤더 등 애플리케이션 데이터 기반으로 트래픽 제어**
- **Load Balancing**(균등 부하 분산)뿐 아니라 **Load Sharing** (비균등 부하 분산) 가능
- 콘텐츠 필터링, 사용자 인증 등 보안 기능 제공
- **예시** : 로그인 요청은 서버 A로, 이미지 요청은 서버 B로 전달

**L2~L7 Switch 비교 요약**

| 계층 | 기준 | 기능 예시 |
| ---- | --- | -------- |
| **L2SW** | MAC 주소 | Switching, Forwarding, Filtering |
| **L3SW** | IP 주소 | L2 + 라우팅, 게이트웨이 |
| **L4SW** | 포트 번호 + IP 주소 | L3 + 부하 분산 (Load Balancer) |
| **L7SW** | 콘텐츠 + 포트 번호 + IP 주소 | L4 + 세션 기반 분기, 보안 제어 |

### 2. 사내망 구성도
#### Access Layer (접속 계층)
- **사내망에서 최하단에 위치**하며 단말기(PC, 프린터, IP Phone 등)가 직접 연결되는 계층
- 일반적으로 **L2 Switch 또는 L2+ 스위치** 사용
- **주 기능**
    - 단말과 네트워크 간 물리적 연결
    - VLAN, 포트 보안
    - 기초적인 트래픽 필터링
- **대표 장비** : L2 스위치, 무선 AP, 허브 (권장하지 않음)

#### Distribution Layer (배포 계층)
- 여러 Access Layer의 스위치를 **중앙에서 집계**하는 역할
- **정책 적용, 라우팅, NAT, 보안 제어의 핵심 지점**
- **주 기능**
    - **인터 VLAN 라우팅**
    - **ACL, NAT, QoS**, 인증 제어
    - 게이트웨이 역할 수행
- **대표 장비** : L3 스위치(Multilayer Switch), 방화벽, 라우터

#### Core Layer (코어 계층)
- 모든 Distribution Layer 장비들을 **초고속으로 연결하는 백본 계층**
- 기업 내부 데이터 흐름의 **속도, 신뢰성, 안정성**을 최우선으로 고려
- **주 기능**
    - 고속 스위칭/라우팅
    - 패킷 처리 지연 최소화
    - 병목 현상 방지
- **대표 장비** : L3 Core Router, 고성능 백본 스위치
> 일반 중소규모 네트워크에서는 **Distribution + Core Layer**를 통합하는 경우도 많음

| 계층 | 주요 기능 | 주 사용 장비 | 특징 |
| --- | -------- | ---------- | ---- |
| **Access** | 단말 연결, VLAN, 기초 보안 | L2 Switch, AP | 사용자 가장 가까운 위치 |
| **Distribution** | 정책 적용, 라우팅, NAT, 보안 | L3 Switch, 방화벽 | 논리적 중심, 게이트웨이 역할 |
| **Core** | 초고속 데이터 전송, 백본 연결 | 고성능 L3 Switch | 속도 우선, 최소 정책 처리 |

#### 이중화 구성 (Redundancy)
- 장비 이중화 : 동일 장비 2대를 구성 (Active-Standby, Active-Active)
- 회선 이중화 : 서로 다른 링크 경로 구성
- 고장 시 자동 전환(Failover)을 통해 고가용성(HA: High Availability) 확보

#### 게이트웨이 (Gateway)
- 서로 다른 네트워크 간 통신을 연결해주는 장비 또는 인터페이스
- 사내망 → 외부망 통신 시 항상 필요
- **역할** : 라우팅, 주소 변환(NAT), 보안 제어

| 장비 유형 | 설명 |
| -------- | --- |
| **라우터** | LAN ↔ LAN (동기종망), LAN ↔ WAN (이기종망) 연결, LAN/WAN 인터페이스 가짐 |
| **멀티레이어 스위치 (L3SW)** | 주로 LAN ↔ LAN 연결에 사용, 속도가 빠르고 통합적 제어 가능 |
| **게이트웨이(논리 개념)** | 방화벽 또는 라우터, L3SW 등으로 구현됨 |

### 3.NAT (Network Address Translation)
- 사설 IP ↔ 공인 IP 변환 기술
- 외부망과 통신 시 사설망 주소를 공인 IP로 변환하여 외부에 노출
- 보안성과 IP 주소 절약을 동시에 달성

| 유형 | 설명 |
| --- | ---- |
| **SNAT (Source NAT)** | 내부 → 외부: 송신자의 사설 IP → 공인 IP로 변환 |
| **DNAT (Destination NAT)** | 외부 → 내부: 목적지 공인 IP → 내부 서버 IP로 변환 |
| **PAT (Port Address Translation)** | 여러 사설 IP가 하나의 공인 IP + 포트 번호로 매핑됨 |

> 일반 가정이나 회사에서는 보통 SNAT + PAT 방식으로 인터넷 접속을 처리

### 4. 보안 솔루션

#### 방화벽(Firewall)
- 내·외부 네트워크 간 통신 흐름을 제어하는 보안 장비
- 미리 정의된 **정책(Policy)**에 따라 허용/차단 결정
- 네트워크 경계에서 비인가 접근을 차단해 보안의 1차 방어선 역할
- **역할**
    - **트래픽 필터링** : IP, Port, Protocol 등을 기준으로 패킷 차단
    - **접근 제어** : ACL, 정책 설정을 통한 네트워크 경로 제어
    - **NAT 기능** : 사설 IP ↔ 공인 IP 변환
    - **세션 상태 추적** : TCP/UDP 세션을 기반으로 허용/차단
    - **암호화 + 터널링 : VPN**
- 방화벽 정책 설정 : 대부분은 **화이트리스트** 기반 정책 설정 (허용만 명시하고 나머지는 기본 차단)
- **한계**
    - 내부에서 발생하는 공격은 탐지/차단 어려움 (ex. 내부 사용자 계정 탈취)
    - **우회 트래픽 (tunneling, 암호화 통신)**을 정확히 분석하기 어려움
    - 비인가 탐지 불가 : 공격인지 정상인지 판단하는 기능은 없음 (→ IDS 필요)
    - 제로데이 공격, 변종 악성코드 차단 어려움

#### IDS (Intrusion Detection System) – 침입 탐지 시스템
- 비인가 접근 시도, 이상 행위, 공격 징후 등을 탐지하는 보안 시스템
- 방화벽이 못 보는 이상 징후를 탐지하여 경고/로그 기록 제공
- 차단 기능은 있긴한데 사용 X → 탐지 전용

**HIDS vs NIDS**

| 항목 | HIDS (Host-based IDS) | NIDS (Network-based IDS) |
| ---- | --------------------- | ------------------------ |
| 위치 | 개별 서버/PC | 네트워크 중간 (스위치, 라우터 근처) |
| 탐지 범위 | 해당 호스트 내 이벤트 | 전체 네트워크 트래픽 |
| 장점 | 사용자 행동, 시스템 로그 상세 분석 | 대규모 네트워크 감시 |
| 단점 | 관리 대상이 많으면 부담됨 | 암호화 트래픽 탐지 어려움 |
| 예시 | 파일 변조 탐지, 루트킷 탐지 | DDoS, 포트 스캐닝 탐지 |
