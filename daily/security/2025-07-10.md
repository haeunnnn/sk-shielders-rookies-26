## 🧠 주요 개념 정리

### 1. OSI 7계층

|   | 계층 | 장비 | 고유 기능 | 예시 |
| - | --- | --- | -------- | ---- |
| 7 | **Application (응용)** | 방화벽, 게이트웨이, 프록시 서버 | - 사용자를 위한 서비스 UI 제공 <br/> - 데이터 생성 | HTTP, FTP, Telnet, SMTP, SNMP, NFS, ... |
| 6 | **Presentation (표현)** | 게이트웨이(일부) | - 인코딩 (이진화) <br/> - 압축화 <br/> - 암호화 | ASCII, UNICODE/jpg, bmp, png, mp4, zip/RSA, DES |
| 5 | **Session (세션)** | 방화벽(일부), 게이트웨이(일부) | - 양 단 간에 서비스 설정, 유지, 해지 <br/> - 서비스 개시 : 인증 <br/> - 서비스 유지 : 지속적 인증 <br/> - 서비스 해지 : 인증값 필요 | SSL |
| 4 | **Transport (전송)** | L4 스위치 | - 양 단 간의 가상 회선(Virtual Line) 설정, 유지, 해지 <br/> - 가상 회선 수립 : 서버 활성화 and 서비스 활성화 <br/> - 가상회선 해지 : 서버 비활성화 or 서비스 비활성화 | TCP (3-way handshake) |
| 3 | **Network (네트워크)** | 라우터 | - 경로 관리와 최적 경로 결정 (Routing) | |
| 2 | **Data Link (데이터 링크)** | 스위치 | - 포워딩 : 데이터 전송을 위해 미디어 접근 방법 제공 <br/> - 공유 매체 접근 제어(MAC) : 충돌 제어, 전송 지연 줄임 <br/> - 오류 제어 : 무결성 점검 | CSMA/CD, CSMA/CA |
| 1 | **Physical (물리)** | 허브, 케이블 | - 물리적인 연결 설정 <br/> - 전기적, 기계적, 기능적, 절차적인 수단 제공 → 가장 통신 규격이 많다 | |

#### 세션 계층 (5계층)

**지속적 인증**
- **세션 설정 및 유지** : 사용자가 한 번 로그인(인증)을 하면, 응용 계층에서 이 인증 상태를 유지하기 위해 세션 계층의 기능을 활용하여 **세션 ID**를 발급하고 관리
- **인증값**은 주로 **쿠키 ID**나 **세션 ID**의 형태로 전달되고, 이는 `ID, PW`와 같다.

> Router : 통신 장비, Routing : 최적 경로를 선정하는 작업, Route : 최적 경로

> LAN은 2계층으로 스위치나 허브를 사용한다. 스위치나 허브는 포워딩 장비로 데이터를 전달(포워딩, 플러딩)하는 역할을 한다. 라우터는 3계층 장비로 갈림길에서 최적의 경로를 결정하는 네비게이션 역할을 한다.
