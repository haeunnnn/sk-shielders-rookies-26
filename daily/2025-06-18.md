## 🧠 주요 개념 정리

### 1. 기초 통계학 개념 소개 

#### 중심 경향성

| 중심 경향 | 사용 목적 | 유용한 상황 |
|-----------|-----------|--------------|
| 평균 | 전체 균형점 파악 | 데이터가 고르게 분포될 때 |
| 중앙값 | 극단값 제거 효과 | 이상치가 있는 경우 |
| 최빈값 | 가장 자주 나타나는 값 | 범주형 데이터 분석 시 |

- **평균**: (합계) ÷ (개수). 이상치에 민감.
- **중앙값**: 정렬 후 중앙 위치 값. 이상치에 강건.
- **최빈값**: 가장 많이 등장한 값. 이산형/범주형에 적합.

> `statistics`, `pandas`로 평균, 중앙값, 최빈값 계산 가능

#### 데이터 분산성

| 척도 | 정의 및 특징 | 활용 상황 |
|------|---------------|-----------|
| 분산 | 평균으로부터의 거리 제곱 평균 | 수학적 분석 |
| 표준편차 | 분산의 제곱근, 원 단위 사용 | 변동성 해석 |
| 사분위수 | 데이터를 4분할한 경계값 | 분포 해석 및 이상치 탐지 |

- **분산**: 편차²의 평균. 단위가 제곱됨.
- **표준편차**: 분산의 제곱근. 해석 용이.
- **사분위수**:
  - Q1: 하위 25%
  - Q2: 중앙값
  - Q3: 상위 25%
  - IQR = Q3 − Q1 → 이상치 탐지 기준에 사용

> `statistics`, `pandas`로 분산, 표준편차, 사분위수 계산 가능

#### 데이터 분포 특성

| 척도 | 정의 및 특징 | 활용 상황 |
|------|----------------|-----------|
| 정규분포 | 평균 중심 대칭 | 자연현상 분석 |
| 왜도 | 좌우 비대칭성 | 데이터 치우침 해석 |
| 첨도 | 분포의 뾰족함, 꼬리 두께 | 극단값 분석 (주식 등) |

- **정규분포**: 평균=중앙값=최빈값, 68%-95% 법칙
- **왜도**:
  - \> 0: 오른쪽 꼬리 (양의 왜도)
  - < 0: 왼쪽 꼬리 (음의 왜도)
- **첨도**:
  - \> 3: 뾰족한 분포
  - < 3: 평평한 분포

### 2. 데이터 통합 및 시각화

#### 데이터 통합

| 기능 | merge | concat |
|------|-------|--------|
| 기준 | 공통 key 기준 | 기준 없이 단순 결합 |
| 방향 | 열 중심 (join 방식) | 행/열 방향 (axis=0/1) |
| 사용 목적 | 관계형 조합 | 단순 병합, 데이터 확장 |

- `merge`: inner, outer, left, right join
- `concat`: axis=0 (행 위로), axis=1 (열 옆으로)

#### 데이터 분포 시각화

| 시각화 | 주요 정보 | 사용 목적 |
|--------|-----------|-----------|
| 히스토그램 | 빈도, 구간(bin) 분포 | 연속형 데이터 분포 확인 |
| 박스플롯 | 중앙값, 사분위수, 이상치 | 분포 요약 및 비교 |
| 산점도 | 두 변수 관계 | 상관관계 시각화 |
| 히트맵 | 변수 간 상관계수 | 상관분석 |
| 페어플롯 | 수치형 변수 전반 | 변수 간 관계 일괄 분석 |
| 카운트플롯 | 범주형 빈도 | 범주형 분포 확인 |

**박스플롯 구성 요소**
- 중앙값: 박스 중앙 선
- Q1, Q3: 박스 하단/상단
- IQR: Q3 - Q1
- 이상치: Q1 − 1.5×IQR 이하, Q3 + 1.5×IQR 이상

### 3. 데이터 분석 - 기초 분석

#### EDA (Exploratory Data Analysis)

**EDA 목적**
- 데이터 구조, 분포, 이상치, 결측치 파악
- 분석 방향 설정 및 가설 수립
- 시각화를 통한 데이터 이해

**EDA 주요 단계**
1. 데이터 기본 정보 확인 (`head()`, `info()`, `describe()`)
2. 결측치 및 이상치 확인
3. 분포 확인 (히스토그램, KDE)
4. 변수 간 관계 분석 (상관계수, 그룹 통계)
5. 시각화 (Matplotlib, Seaborn 등)

> EDA 결과: 데이터 구조/특성 이해, 전처리 전략, 분석 방향 수립

#### 데이터 기본 구조 파악

| 항목 | 설명 |
|------|------|
| 데이터 크기 | 행/열 수 파악 |
| 데이터 타입 | 수치형, 범주형, 문자형, 날짜형 등 |
| 변수명 | 컬럼명과 의미 확인 |
| 결측값 | NaN 또는 null 값 탐지 |
| 분포 | 변수의 분포 확인 |
| 중복값 | 동일 행의 반복 여부 확인 |

**활용**
- 전처리 전략 수립 (예: 수치형 평균, 범주형 빈도 분석)
- 시각화 전략 결정 (scatter, bar 등)

### 4. 데이터 분석 - 그룹화와 집계

#### 그룹화와 집계

**그룹화**
- 특정 컬럼 기준으로 데이터를 묶어 통계 처리  
- 예: `groupby('부서')['급여'].mean()`

**피벗 테이블**
- 행/열 기준으로 다차원 요약 가능  
- 예: 매장별/월별 평균 매출  
- 다양한 집계 함수 가능 (`aggfunc`)

| 기법 | 설명 | 사용 예 |
|------|------|--------|
| GroupBy | 특정 기준으로 그룹 후 요약 | 부서별 평균 급여 |
| Pivot Table | 다차원 테이블 재구성 | 매장·월별 총 매출 분석 |

#### 데이터 비교 분석

| 방법 | 목적 |
|------|------|
| 기술 통계 | 평균, 중앙값, 범위 등 비교 |
| 시각화 | 히스토그램, 박스플롯, 산점도 |
| 상관 분석 | 상관계수로 변수 관계 파악 |
| 차이 분석 | 변화량 계산 |
| 피벗 테이블 | 조건별 비교 및 분석 |

**활용 예시**
- 제품별 판매 비교  
- 실험 전후 성과 비교  
- 지역 간 수치 분석

### 5. 상관관계와 회귀 분석

#### 상관관계 (Correlation)

| 상관계수 | 의미 |
|----------|------|
| 1 | 완전한 양의 상관 |
| 0.8 | 강한 양의 상관 |
| 0 | 상관 없음 |
| -0.8 | 강한 음의 상관 |
| -1 | 완전한 음의 상관 |

- **상관행렬**: 여러 변수 간 상관계수를 표로 정리
- **주의**: 상관관계는 인과관계를 의미하지 않음

#### 회귀 분석 (Regression)

**단순 선형 회귀**
- Y = aX + b 형태  
- **a**: 기울기, **b**: 절편

**핵심 개념**
- **잔차**: 실제값 - 예측값  
- **최소제곱법**: 잔차 제곱합을 최소화  
- **R² 값**: 모델 설명력 (0~1)

**분석 도구**
- 산점도: 관계 시각화  
- 회귀선: 선형 예측 시각화  
- 상관계수: 수치적 관계 해석

**상관 vs 인과**
- 상관관계: 함께 움직이는 경향  
- 인과관계: 한 변수가 직접 영향을 줌  
> 예: 광고비 ↔ 매출 데이터 → 상관은 높아도 인과는 분석 필요
