## 🧠 주요 개념 정리

### 1. 비지도학습(Unsupervised Learning)
- 레이블이 없는 데이터로부터 패턴이나 구조를 학습하는 방법
- 예측보다는 탐색과 구조 발견이 목적
- 대표 응용 분야
  - **군집화(Clustering)**: 유사한 데이터끼리 그룹화
  - **차원 축소(Dimensionality Reduction)**: 데이터 요약 및 시각화
  - **이상치 탐지(Anomaly Detection)**: 비정상 데이터 식별
  - **추천 시스템(Recommendation)**: 유사 사용자 기반 추천

#### 지도학습 vs 비지도학습

| 구분 | 지도학습 | 비지도학습 |
|------|----------|-------------|
| 레이블 유무 | O (정답 제공) | X (입력만 제공) |
| 목적 | 예측 | 구조/패턴 발견 |
| 결과 | 예측 모델 | 그룹/패턴/시각화 |
| 예시 | 스팸 분류, 가격 예측 | 고객 세분화, 시각화 |

#### 주요 기법
- **Clustering**: K-Means, DBSCAN, Hierarchical
- **Dimensionality Reduction**: PCA, t-SNE, UMAP
- **Anomaly Detection**: Isolation Forest, LOF, Autoencoder

### 2. 군집화(Clustering)
- 비슷한 속성을 가진 데이터들을 하나의 클러스터로 묶는 작업
- 사전 레이블 없이 데이터를 구조화할 수 있음
- **주요 목표**
  - 데이터 구조 파악 : 데이터를 시각화 하거나 그룹화하여 숨겨진 패턴을 발견
  - 유사성 기반 그룹화 : 데이터 포인트들 간의 유사성을 기준으로 분류하여 각 그룹이 내포하는 의미를 이해
- **작동 방식**
  - 유사성 측정 : 데이터 포인트 간의 유사성을 측정하기 위해 거리 계산(예: 유클리드 거리)을 사용
  - 그룹화 : 유사한 데이터 포인트들을 같은 그룹으로 묶음

#### 활용 예시
- **고객 세분화**: 마케팅 전략 최적화
- **이미지 세그멘테이션**: 물체 인식, 의료 영상 분석
- **문서 분류**: 주제별 그룹화 및 검색 향상
- **이상치 탐지**: 사기 거래/비정상 네트워크 탐지
- **추천 시스템**: 유사 행동 사용자 그룹화 기반 추천

### 3. K-Means 알고리즘
- 대표적인 군집화 알고리즘
- 데이터를 K개의 클러스터로 나눔 → 반복적이고 간단한 방식으로 데이터를 그룹화하며, 각 클러스터는 하나의 중심(centroid)으로 설정

#### 작동 원리
1. 클러스터 수 K 설정 및 초기 중심(Centroid) 설정  
2. 각 데이터 포인트를 가장 가까운 중심에 할당  
3. 클러스터별 평균값으로 중심 재계산  
4. 중심 변화가 없거나 반복 종료 조건 도달 시 종료

#### 사용 예
- **고객 세분화**, **이미지 압축**, **문서 분류**

#### 적용 단계
1. 데이터 준비 및 정규화
2. K값 설정
  - **엘보우 방법(Elbow Method)**를 통해 최적의 𝐾값을 선택
    - 여러 𝐾값에 대해 K-Means를 실행하고, 각 경우의 클러스터 내 데이터의 거리 합(WCSS, Within-Cluster Sum of Squares)을 계산
    - 𝐾값에 따른 WCSS를 그래프로 그려, 그래프의 기울기가 급격히 완화되는 지점(엘보우 포인트)에서 최적의 𝐾를 선택.

3. 알고리즘 실행
4. 결과 평가 및 시각화

#### 클러스터링 결과 시각화 도구
- **Matplotlib**: 산점도(scatter plot)
- **Seaborn**: 페어 플롯(Pair Plot) 등
- **PCA**: 고차원 데이터를 2D/3D로 축소

#### 클러스터 해석
- 클러스터 중심값과 분포로 각 그룹 특성 분석
  - 예: 구매 빈도 높음/낮음, 평균 소비금액 비교
- 클러스터 간의 차이점 파악

#### 클러스터 품질 평가
- **응집도**: 클러스터 내 데이터 간 거리 → 가까이 모여 있을수록 해당 클러스터는 응집도가 높다고 평가
- **분리도**: 클러스터 간 거리 → 클러스터 간의 거리가 멀수록 분리도가 높다고 평가
- **실루엣 점수 (Silhouette Score)** : 클러스터의 응집도와 분리도를 동시에 평가할 수 있는 강력한 지표
  - 1에 가까울수록 좋은 클러스터링
  - 적절한 K 값을 찾는 데 활용됨
    ① 여러 𝑘값에 대해 K-Means를 실행
    ② 각 𝑘값에 대해 실루엣 점수를 계산
    ③ 실루엣 점수 시각화
    ④ 실루엣 점수가 가장 높은 𝑘값을 선택

| 평가 항목 | 설명 |
|-----------|------|
| 응집도 | 클러스터 내부 데이터가 얼마나 밀접한가 |
| 분리도 | 클러스터 간의 간격이 얼마나 큰가 |
| 실루엣 점수 | 응집도와 분리도를 동시에 고려한 종합 지표 |

### 4. K-Means 외의 군집화 알고리즘

#### Hierarchical Clustering (계층적 군집화)
- 데이터 간 계층적 구조를 기반으로 트리 형태의 클러스터를 구성
- **두 가지 방식**
  - **병합형(Agglomerative)**: 개별 클러스터에서 시작해 병합
  - **분할형(Divisive)**: 전체를 하나로 시작해 분할

**특징**
- 클러스터 수 지정 불필요  
- 덴드로그램으로 시각적 확인 가능  
- 대용량 데이터에 비효율  
- 병합/분할 초기 결정의 영향 큼

**작동 방식 (병합형 기준)**
① 각 데이터 포인트를 하나의 클러스터로 간주
② 두 클러스터 간의 거리(또는 유사도)를 계산
③ 가장 가까운 두 클러스터를 병합
④ 클러스터가 하나가 될 때까지 반복

**클러스터 간 거리 계산법**

| 방법 | 설명 |
|------|------|
| 최단 연결법(Single Linkage) | 가장 가까운 두 점의 거리 |
| 최장 연결법(Complete Linkage) | 가장 먼 두 점의 거리 |
| 평균 연결법(Average Linkage) | 모든 점의 평균 거리 |

#### DBSCAN
- 밀도 기반 군집화 알고리즘
- 데이터가 밀집된 영역을 클러스터로 정의
- 밀도가 낮은 데이터는 노이즈로 간주 → 이상치(노이즈)를 처리 가능
- 클러스터 수(𝑘)를 미리 지정할 필요 없음
- 밀도가 다른 데이터나 비구형 데이터를 효과적으로 처리하며, 이상치 검출에 강점이 있음.
 - 고차원 데이터에서는 거리 계산이 왜곡될 수 있음

**핵심 개념**
- `ε`: 밀집 판단 거리 임계값  
- `MinPts`: 핵심 포인트 기준 이웃 수  
- Core Point: ε 반경 내 MinPts 이상  
- Border Point: Core 주변에 있으나 MinPts 미달  
- Noise: 어떤 클러스터에도 속하지 않음

**동작 방식**
① 각 데이터 포인트에 대해 𝜖-이웃을 계산
② 𝜖-이웃 내의 데이터 포인트 수가 MinPts이상이면 해당 포인트는 핵심(Core)포인트로 간주
③ 핵심 포인트와 연결된 이웃 데이터는 같은 클러스터로 그룹화
④ 밀도가 낮은 포인트는 노이즈로 분류.

**장점**
- 비정형 클러스터 형태 처리 가능  
- 이상치 감지 가능  
**단점**
- 고차원 데이터에 취약  
- 파라미터 설정 중요

### 5. 차원 축소(Dimensionality Reduction)

- 고차원 데이터 → 저차원 데이터로 변환하여 효율성, 시각화, 노이즈 제거 가능

**차원 축소의 필요성**
- 차원의 저주 (Curse of Dimensionality) 회피  
- 계산 효율성 향상, 과적합 방지  
- 시각화 가능 (2D, 3D 변환)

**활용 예시**
- 이미지 데이터, 유전자 데이터, 추천 시스템

#### PCA (Principal Component Analysis)
- 가장 널리 쓰이는 선형 차원 축소 기법
- 데이터 분산이 가장 큰 방향으로 주성분(Principal Components)을 정의하고, 이들로 데이터를 투영

**PCA 작동 원리**
1. **정규화(Standardization)** : 각 피처의 값이 서로 다른 범위를 갖고 있으면 결과에 영향을 미치기 때문에, 평균이 0이고 분산이 1인 데이터로 변환 
2. **공분산 행렬 계산** : 공분산 행렬(Covariance Matrix)은 각 피처 간의 상관관계를 나타냄
3. **고유값/고유벡터 계산**  
  - 고유값 : 주성분이 설명하는 분산의 크기 (중요도)
  - 고유벡터 : 주성분의 방향 (새로운 축)
4. **주성분 선택** : 중요한 정보를 설명하는 주성분(변동성을 많이 설명하는 축)만 선택(예: 누적 분산 95% 이상)  
5. **데이터 투영** : 원본 데이터를 선택된 주성분 축으로 투영

**주성분**
- 데이터의 분산(정보량)이 가장 큰 방향을 나타내는 축
- PCA는 데이터의 분산을 최대화하는 방향을 찾아 새로운 좌표축을 정의하고 이를 주성분이라고 함
- **특징**
  - **PC1**: 최대 분산 방향  
  - **PC2**: PC1과 직교하며 두 번째로 큰 분산  
  - 각 주성분은 변동성이 큰 방향 순으로 선택됨

**데이터 투영**
- 정보를 최대한 유지하면서 차원을 줄이는 과정  
- 시각화 및 계산 효율성 확보
- 중요한 정보만 유지, 차원 축소, 시각화 가능

### 6. 이상치 탐지(Outlier Detection)

- 일반적인 패턴에서 벗어난 비정상적 데이터 식별
- **응용 사례**: 금융 사기, 기계 고장 조기 경고, 건강 이상 감지

#### Isolation Forest
- 데이터를 반복적으로 무작위 분할하며 이상치 탐지
- 이상치는 적은 단계로 분리됨

**작동 방식**
1. 무작위 샘플링 : 임의 분할(feature & value)  
2. 평균 분리 깊이 측정 : 이상치 일수록 다른 데이터로부터 분리되는 데 필요한 단계(depth)가 작음
3. 다수 트리에서 평균 깊이 계산 : 데이터를 무작위로 분할하여 여러 개의 이진 트리(isolation tree)를 생성 → 각 데이터 포인트가 나뉘는 평균 깊이를 계산
4. 높은 점수를 받을수록 이상치일 가능성이 높음

**장점**
- 고속 처리 (O(n)), 대용량 처리  
- 레이블 불필요
**단점**
- 고차원 데이터 비효율  
- 복잡한 분포에 한계

#### DBSCAN (이상치 탐지로 활용)
- 밀도가 낮은 데이터를 자동으로 이상치로 분류
- 클러스터와 이상치 동시에 처리 가능

**장점**
- 클러스터 모양에 제약 없음
- 사전 클러스터 개수 지정 불필요
- 이상치 탐지와 클러스터링을 동시에 수행
**단점**
- ε와 MinPts파라미터의 선택이 성능에 크게 영향을 미침
- 고차원 데이터에 적용할 경우 효율성 저하

**Isolation Forest와 DBSCAN 비교**

| 비교 항목 | Isolation Forest | DBSCAN |
|-----------|------------------|--------|
| 접근 방식 | 데이터 분리 기반 | 밀도 기반 |
| 확장성 | 우수 | 낮음 (고차원에서) |
| 파라미터 | 적음 | ε, MinPts 설정 필요 |
| 주요 활용 | 금융, 보안 | 위치 기반, 이상 행동 |
