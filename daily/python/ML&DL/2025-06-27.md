## 🧠 주요 개념 정리

### 1. FastAPI

#### FastAPI
- 고성능 웹 프레임워크: Python 기반의 비동기 웹 프레임워크로, 빠른 성능을 제공
- ASGI 지원: 비동기 요청을 처리하고 WebSocket과 같은 실시간 통신을 지원
- 자동화된 API 문서화: Swagger UI와 ReDoc을 통해 자동으로 API 문서를 생성
- Pydantic 통합: 데이터 유효성 검사와 데이터 모델링을 쉽게 처리
- 타입 힌트 기반: Python의 타입 힌트를 활용하여 자동으로 데이터 검증
- 간단한 코드: 적은 양의 코드로도 강력한 기능을 구현할 수 있어 생산성이 높음

#### Uvicorn
- 초고속 ASGI 서버(Asynchronous Server Gateway Interface)
- ASGI 표준 지원 (비동기 프로그래밍, 실시간 기능 처리) -> 채팅, 알림 시스템과 같은 실시간 섭비스를 구현에 유리
	- 간단한 실행 -> `uvicorn main:app --reload`
	- 자동 리로딩 지원 -> `--reload` 옵션
- FastAPI와의 높은 호환성

#### Pydantic
- Python에서 가장 널리 사용되는 데이터 유효성 검사 라이브러리 -> 데이터 유효성 검사 자동 수행
- Python 3.8 이상에서 데이터가 어떻게 구성되어야 하는지 정의 ->데이터 모델링: 클래스 기반 데이터 구조 정의
- Pydantic으로 데이터의 유효성을 검사
	-> 타입 힌트 지원: 직관적으로 명확한 데이터 정의
	-> 자동 타입 변환 지원
	-> FastAPI와의 통합: 입력 데이터 검증에 유용

#### 대화형 API 문서
- 자동 대화형 API 문서를 볼 수 있음 -> Swagger UI

**Swagger**
- API 설계 및 문서화 도구
- 주요 기능 -> API 문서화, Swagger UI 제공, 코드 생성
- API 명세서(Swagger 파일)
- 자동화된 문서 생성
- API 테스트 및 클라이언트 코드 생성 지원

#### 대안 API 문서
- 다른 자동 문서 ReDoc 제공
	- API 문서를 제공하기 위해 사용하는 도구 중 하나
	- FastAPI는 작성된 코드와 함께 자동으로 ReDoc 문서를 생성
	- ReDoc은 읽기 쉽고, 탑색하기 쉬운 인터페이스를 제공 -> API의 구조를 이해하고, 엔드포인트와 파라미터를 쉽게 확인
	- 코드가 변경되면 ReDoc 문서도 자동으로 업데이트되어 항상 최신 상태의 문서를 유지

#### FastAPI의 추가 기능
- 입력 데이터 변환
	- JSON
	- 경로 매개변수/쿼리 매개변수
	- 쿠키/헤더
	- 폼(Forms)/파일

### 2. Flask
- Python 기반의 경량 웹 프레임워크
- WSGI 기반 및 Jinja2 템플릿 엔진을 사용
- 빠른 시작과 유연성을 제공하는 마이크로 프레임워크

**관련 예시**  
- `@app.route()`로 URL과 함수 매핑  
- `app.run()`으로 서버 실행

#### URL Routing & Methods
- `@app.route()`로 URL과 함수 연결
- `add_url_rule()`로 외부 함수 연결 가능
- HTTP 메서드(GET, POST, PUT, DELETE 등) 지정 가능

**하위 항목**
- `url_for()`로 동적 URL 생성
- URL 컨버터로 데이터 타입 지정 가능 (예: `<int:id>`)

#### 템플릿 및 정적 파일
- Jinja2 엔진을 통해 HTML 템플릿 렌더링 지원
- `render_template()` 사용
- 템플릿 구문: `{{ ... }}`, `{% ... %}`, `{# ... #}`  
- `/static` 경로에서 CSS/JS 등 정적 파일 제공

#### 요청 객체 & 쿠키
- `request.form`, `request.args`, `request.cookies`, `request.files` 등으로 클라이언트 요청 정보 접근 가능
- 쿠키 설정: `response.set_cookie()`
- 쿠키 읽기: `request.cookies.get()`

#### Session (로그인 처리 등)
- 사용자별 세션 데이터 저장 및 관리
- `session['user'] = 'username'`으로 세션 설정
- `session.pop('user')`으로 삭제
- 쿠키 기반 저장 + 서버 측 암호화 지원

#### 파일 업로드
- HTML 폼에서 multipart/form-data 설정 필요
- 파일 접근: `request.files['file']`
- 파일 이름: `request.files['file'].filename`
- 설정: 
  - `app.config['UPLOAD_FOLDER']` : 업로드 디렉토리 지정  
  - `app.config['MAX_CONTENT-PATH']` : 최대 크기 제한
