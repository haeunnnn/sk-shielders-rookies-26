## 🧠 주요 개념 정리

### 6. Web Search

- 웹 검색 도구는 최신 데이터를 검색하여 응답에 활용
- `type: web_search_preview`로 도구 지정
- 위치 정보(city, country, timezone) 지정 가능

#### 컨텍스트 크기 설정

| 수준 | 설명 |
|------|------|
| high | 높은 품질, 비용, 느린 속도 |
| medium | 기본값, 균형 잡힌 설정 |
| low | 빠른 속도, 낮은 비용, 낮은 품질 가능성 |

- 검색 도구 사용 토큰은 모델 컨텍스트 창에 영향을 주지 않으며 응답 후 소멸됨

### 7. File Search

- 업로드된 파일에서 정보를 검색해 응답에 활용
- 벡터 저장소(vector store)를 생성하고 파일 업로드 후 사용
- 의미 기반 검색 지원
- include 매개변수로 검색 결과를 응답에 포함할 수 있음

#### 사용 순서

1. 벡터 스토어 생성
2. 파일 업로드
3. 상태 완료 확인
4. file_search 도구로 등록
5. 응답 생성 시 include 옵션 활용

### 8. Function Calling 구현 핵심 함수

#### handle_function_call()

1. 응답에 `function_call` 존재 여부 확인
2. JSON 형식 arguments 파싱
3. 호출할 함수 분기 처리
4. 함수 실행 결과를 `role: function` 메시지로 생성
5. messages에 append하여 응답 이어가기

#### chat()

- 사용자 입력부터 응답까지 대화 흐름 전체를 관리
- function_call이 존재할 경우 handle_function_call() 호출 후 messages 업데이트
- 최종 assistant 응답 반환

### 1. Streamlit을 활용한 프론트엔드 서버와 구성 요소 이해

#### 프론트엔드 서버란?
- 사용자와 웹 애플리케이션 사이에서 UI를 제공하는 서버
- 사용자 요청을 백엔드 서버에 전달하고, 백엔드 응답을 시각적으로 표현
- 예: 브라우저에서 Streamlit 서버 접속 → 화면 UI 렌더링

**하위 개념**
- 사용자 요청 처리: HTML, CSS, JS 등 프론트 자원 제공
- 데이터 교환 처리: 백엔드(FastAPI)와 통신, 사용자 입력 전송 및 결과 수신

**하위 항목**
- 클라이언트 : 브라우저
- 프론트엔드 서버 : Streamlit
- 백엔드 서버 : FastAPI, GPT 기반 assistant

### 2. Streamlit의 역할
- Python 기반 프레임워크로, 데이터 기반 웹 앱 제작 가능
- 자체적으로 프론트엔드 서버 역할 수행

#### 특징
- UI 위젯 제공 (버튼, 입력창, 슬라이더 등)
- 사용자 입력 처리 후 즉시 결과 반영
- SPA 방식처럼 새로고침 없이 반응형 UI 제공

### 3. Streamlit 주요 기능 및 컴포넌트

#### 콘텐츠 표시
- `st.write()`: 텍스트, 리스트, 그래프 등 다양한 타입 출력
- `st.write_stream()`: 실시간 생성형 응답 표시
- 매직: 한 줄 값 자동 출력 (실제론 `st.write()` 처리)

#### 텍스트 요소
- `st.markdown()`: 마크다운 지원 텍스트 출력
- `st.title()`, `st.header()`, `st.subheader()`: 제목 계층 구조
- `st.caption()`, `st.text()`, `st.code()`: 작은 글씨, 고정폭, 코드
- `st.echo()`: 코드 + 실행 결과 함께 표시
- `st.latex()`: LaTeX 수식 출력
- `st.divider()`: 수평선 출력
- `st.button()`, `st.download_button()`, `st.checkbox()`: 사용자 입력 UI

#### 입력 위젯
- `st.text_input()`: 텍스트 입력 필드
- `st.radio()`: 라디오 버튼
- `st.slider()`: 범위 입력 슬라이더

#### 미디어 요소
- `st.image()`: 이미지 표시
- `st.audio()`: 오디오 재생
- `st.video()`: 동영상 재생

## ❓ 궁금한 점

- **Streamlit은 프론트엔드 서버 역할을 자체적으로 수행한다고 했는데, 일반적인 프론트엔드 프레임워크(React, Vue 등)와 어떤 차이가 있을까?**
    - Streamlit은 Python 기반으로 프론트와 백을 통합해서 빠르게 데이터 앱을 만들 수 있음. React/Vue는 JS 기반으로 복잡하고 세밀한 UI 제작에 유리하지만 설정과 개발 난이도가 높음.
    - 차이점

| 항목 | Streamlit | React/Vue |
| ---- | ---------- | ---------- |
| **언어** | Python 기반 | JavaScript 기반 |
| **주요 목적** | 빠르게 데이터 앱, 대시보드, AI 데모 구축 | 복잡한 UI를 갖춘 웹 애플리케이션 개발  |
| **프론트엔드 구성** | 별도 프론트엔드 코드 없이 Python 코드로 UI 구성 | HTML/CSS/JS로 UI 구성 필요   |
| **서버 역할** | 자체적으로 프론트엔드 서버 포함 | 보통 Node.js 기반 개발 서버 활용  |
| **개발 난이도** | 매우 낮음 (Python 코드만 작성) | 비교적 높음 (상대적으로 많은 설정 필요) |
| **단점** | 커스터마이징 제약, 복잡한 UX 어려움 | 자유도 높지만 러닝커브 존재 |

- Streamlit은 빠른 프로토타이핑과 데이터 중심 앱에 적합하며, React/Vue는 정교한 인터페이스가 필요한 일반 웹앱 개발에 적합

- **Streamlit에서 사용자 인터랙션(예: 버튼 클릭, 입력 이벤트 등)을 어떻게 비동기적으로 처리할 수 있을까?**
    - Streamlit은 사용자 이벤트마다 전체 코드가 다시 실행됨. st.session_state로 상태 기억, st.write_stream()으로 실시간 출력 등으로 비동기처럼 구현 가능.

| 기능 | 설명 |
| ---- | ---- |
| `st.session_state` | 변수 값을 유지해 이전 사용자 입력 기억 |
| `st.spinner()` | 특정 코드 블록 처리 중 로딩 애니메이션 표시 |
| `time.sleep()` + `st.empty()` | 타이핑 효과 등 유사한 비동기 UI 구현 |
| `st.write_stream()` | 생성기(generator)를 통한 실시간 스트리밍 출력 |

- **Streamlit은 챗봇 외에 어떤 용도로 활용될 수 있을까?**
    - 데이터 대시보드 : Pandas, Plotly 등과 함께 사용해 실시간 분석 시각화 앱 구현
    - ML 모델 시연/테스트 : 사용자 입력값을 바탕으로 모델 예측값을 실시간 보여주는 데모 앱
    - AutoML 프론트엔드 : 파일 업로드 후 학습/평가 결과를 인터랙티브하게 표시
    - 설문지/입력 폼 앱 : 다양한 입력값을 수집하고 분석하는 앱 제작
    - 보고서 자동화 UI : 결과를 정리해보고 다운로드 가능한 형태로 시각화
