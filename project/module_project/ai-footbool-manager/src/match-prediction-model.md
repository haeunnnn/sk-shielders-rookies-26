# 축구 경기 승패 예측 모델 보고서

## 1. 프로젝트 개요

본 문서는 전체 프로젝트의 일환으로, 축구 경기 결과 중 **홈팀의 승리 여부를 예측**할 수 있는 머신러닝 모델을 시험적으로 구현한 작업을 정리한 것입니다.  
이 작업은 예측 모델의 가능성과 구조를 탐색해보는 **실험적인 성격**을 띠며, 향후 실제 적용 가능성 및 성능 개선을 위한 참고 자료로 사용하고자 합니다.

- 사용 데이터: **2019년부터 2025년까지의 EPL 경기 기록**
- 알고리즘: **XGBoost**
- 주요 지표: **Elo 점수**, 최근 경기 폼, 기대 득점(xG) 등
- 목적: 홈팀 승리 여부 예측

## 2. 데이터셋 정보

### 2.1 데이터 개요
- **파일명:** `EPL_2019_2025.csv`  
- **예측 목표:** 홈팀 승리 여부  
- **범위:** 2019–2025 시즌 EPL 경기  

데이터는 경기 단위로 구성되며, 주요 열은 다음과 같습니다

- 경기 일정
- 팀 성능 지표 (Elo)
- 최근 폼
- 기대 득점 (xG)
- 베팅 확률 등

### 2.2 주요 입력 피처
- `HomeElo`, `AwayElo`: 경기 시점의 Elo 점수  
- `elo_diff`: 홈팀 - 원정팀 Elo 차이  
- `Form3Home`, `Form5Home`: 홈팀 최근 3, 5경기 성적  
- `Form3Away`, `Form5Away`: 원정팀 최근 3, 5경기 성적  
- `h_xg`, `a_xg`: 기대 득점 (Expected Goals)  
- `xG_diff`, `xg_margin`, `xg_ratio`: 파생 변수  
- `rolling_xg_home_5`, `rolling_xg_away_5`: 최근 5경기 평균 xG  
- `elo_change_home`, `elo_change_away`: Elo 변화량  
- `result`: 실제 경기 결과  
  - 0 = 무승부  
  - 1 = 원정 승  
  - 2 = 홈 승  

> ⚠️ 시즌 초반 경기에는 xG, 폼, 롤링 평균 등 일부 변수에 결측치가 존재합니다.

## 3. 모델 설계 (`xgb_model.pkl`)

### 3.1 예측 목적
- **목표:** `result == 2`인지를 예측 (홈 승)  
- **유형:** 이진 분류  
  - 1 = 홈 승  
  - 0 = 무승부 or 원정 승  

### 3.2 학습 및 처리 흐름

1. **데이터 전처리**
   - 2021년 이후의 경기만 사용  
   - 주요 피처 및 결과값에 결측치가 있는 행 제거  

2. **라벨 정의**

```python
   y = (result == 2)
```

3. **모델 구성**
    - 알고리즘: XGBoost(`XGBClassifier`)
    - 하이퍼파라미터
        - `n_estimators = 100`
        - `max_depth = 4`
        - `learning_rate = 0.1`
        - `subsample = 0.8`
        - `colsample_bytree = 0.8`
        - `eval_metric = 'logloss'`
        - `use_label_encoder = False`

## 4. 모델 성능 평가
### 4.1 정확도
- **Accuracy**: 75.2%

### 4.2 정밀도 / 재현율 / F1-score

| 클래스 | Precision | Recall | F1-score | Support |
| ----- | ---------- | ------ | -------- | ------- |
| 무/원정승 (0) | 0.79 | 0.79 | 0.79 | 122 |
| 홈팀 승 (1)  | 0.69 | 0.70 | 0.70 | 84 |

- **Macro Average**: 0.73
- **Weighted Average**: 0.74

### 4.3 혼동 행렬 (Confusion Matrix)
|      | 예측 0 | 예측 1 |
| ---- | ------ | ----- |
| 실제 0 | 96   | 26   |
| 실제 1 | 25   | 59   |

모델의 전반적인 정확도는 약 **75.2%**로, 홈팀 승리 여부 예측에 비교적 안정적인 성능을 보였습니다.
무/원정 승(클래스 0)에 대해 **정밀도 및 재현율 79%**로 우수하지만, 홈팀 승(클래스 1)에 대해서는 상대적으로 낮은 수치를 보여 데이터 불균형 또는 과적합 가능성이 존재합니다.

## 5. 예측 시스템 (predict.py, get_model_input.py)
### 5.1 목적
- 두 팀 이름과 경기 날짜를 입력받아, 홈팀의 승리 확률을 예측
- 날짜를 기준으로 예측 / 복기 모드 자동 판단

## 5.2 동작 구조
1. **모드 판별**
- 미래 날짜 → 예측 모드
- 과거 날짜 → 복기(검증) 모드 (실제 결과와 비교)

2. **입력 생성 및 모델 로딩**
- `get_model_input()` → 피처 자동 생성
- `joblib.load("xgb_model.pkl")` → 모델 로딩

3. **예측 수행**
- `model.predict()` → 홈팀 승/패 예측

### 5.3 예제 입력

```python
home_team = "Liverpool"
away_team = "Everton"
match_date = "2024-10-26"
```

### 5.4 출력 예시 (터미널)

```makefile
📅 날짜: 2024-10-26 (예측 모드)
🎯 예측 결과: 무/원정승
📊 예측 확률:
홈승: 31.77%
무/원정승: 68.23%
```

## 6. 주의사항 및 개선 계획
- `prob_home`, `prob_draw`, `prob_away` 등의 피처는 현재 `NaN` 값이며, API 연동을 통한 보완이 계획되었으나 제약으로 인해 삭제 예정
- 팀 이름 정확히 입력 필요 (오탈자, 약칭 인식 불가)
- 예측 시 `NaN` 값은 0으로 대체

## 7. 결론 및 활용 방안
본 모델은 홈팀 승리 여부를 **비교적 높은 정확도(75.2%)**로 예측하였으며,
예측 기능의 프로토타입으로는 적절한 성능을 보였습니다.

→ 이로 인해 일반화 성능이 낮아, 실제 서비스에는 부적합하다고 판단됩니다.

향후에는

- 데이터 정제 및 보완
- 입력 데이터 소스 확장

등을 통해 실제 서비스 적용 가능한 수준의 모델로 발전시키는 것을 목표로 합니다.
